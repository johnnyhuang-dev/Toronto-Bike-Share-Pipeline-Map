*** Toronto BikeShare Map ***

Hey there, this repo contains the files to run a simple website that tracks the BikeShare availability all around Toronto.   

I will build a data pipeline to ingest, load, and transform data gathered online about the availability of BikeShare bikes across the city.   

I'll be adding more details about this project as I continue building it.    

Hope this project will help fellow Torontonians and visitors explore the city with more peace of mind and not worrying about reliably finding a bike.
